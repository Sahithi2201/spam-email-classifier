# Spam Email Classifier

## Project Overview
This project demonstrates how machine learning can classify text messages as spam or not spam using Python.

## Objectives
- Analyze message content.
- Convert text into numerical features.
- Train a machine-learning classification model.
- Evaluate the model and predict labels for new messages.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes

## Methodology
1. Prepare labeled spam and normal messages.
2. Split the dataset into training and testing sets.
3. Convert text into TF-IDF features.
4. Train a Multinomial Naive Bayes classifier.
5. Evaluate predictions using accuracy and a classification report.
6. Test custom messages.

## How to Run
Open the notebook in Google Colab and run the code cells in order.

## Dataset and Limitations
This project currently uses a small, illustrative dataset of 16 messages. Its evaluation results are not representative of real-world performance. A larger, diverse labeled dataset is required for a reliable spam filter.

## Future Improvements
- Train with a larger public spam dataset.
- Compare Naive Bayes with Support Vector Machines.
- Build a simple web interface.
- Explore integration with an email system.
